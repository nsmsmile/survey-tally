# survey-tally

엑셀에서 복사한 설문 응답을 붙여넣으면 문항별 결과 표를 보여 주는 `index.html` 한 장짜리 집계기입니다.

- 외부 라이브러리·외부 글꼴·분석 도구를 쓰지 않습니다.
- 붙여넣은 데이터는 브라우저 안에서만 계산하며, 보내거나 저장하지 않습니다. CSP(`default-src 'none'`)가 네트워크 요청을 막습니다.

## 쓰는 법

1. `index.html`을 브라우저로 엽니다(내려받아 열어도 되고, GitHub Pages로 올려도 됩니다).
2. 엑셀에서 **머리글 줄까지** 범위를 복사해 입력칸에 붙여넣습니다.
3. 결과 표가 바로 나옵니다: 문항 / 유효 응답 / 평균 / 빈 응답 / 제외

## 집계 규칙

- 첫 열(응답번호)은 집계하지 않습니다.
- 칸 값의 앞뒤 공백을 지운 뒤 `1`~`5` 중 하나면 **유효**, 비었으면 **빈 응답**, 그 밖이면 **제외**.
- 평균 = 유효 응답의 합 ÷ 유효 응답 수, 소수 셋째 자리에서 반올림해 둘째 자리까지. 유효가 0이면 `-`.
- 칸 수가 머리글보다 모자란 줄은 모자란 칸을 빈 응답으로 셉니다. 넘치는 칸은 무시합니다.

자세한 판단 근거는 [PLAN.md](PLAN.md)에 있습니다.

## 개발

계산 로직은 `index.html`의 `<script id="tally-core">`에 화면과 분리되어 있고, 시험은 그 블록만 꺼내 Node에서 실행합니다. 외부 패키지가 필요 없습니다(Node 22 이상).

```bash
npm test
```

`index.html`의 `<script>`나 `<style>`을 고쳤다면 CSP 해시를 갱신해야 합니다(안 하면 페이지 시험이 실패하고, 브라우저가 스크립트를 막습니다).

```bash
npm run csp
```
