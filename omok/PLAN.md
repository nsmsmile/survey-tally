# 10×10 오목 계획서

## 목표

브라우저에서 바로 하는 10×10 오목. `omok/index.html` 한 파일, 외부 라이브러리·글꼴·네트워크 없음.
기존 설문 집계기(저장소 맨 위 `index.html`)와는 독립된 별개 작업이다.

## 규칙

- 판: 가로 10줄 × 세로 10줄의 교차점 100곳.
- 두 사람이 한 화면에서 번갈아 둔다. 흑이 먼저.
- 빈 교차점에만 둘 수 있다.
- 가로·세로·대각선으로 같은 색 돌이 **5개 이상** 이어지면 그 사람이 이긴다(자유 오목: 6목 이상도 승리, 렌주 금수 없음).
- 100곳이 모두 차고 승자가 없으면 무승부.
- 승부가 나면 더 둘 수 없다.

## 기능

- 차례·승패·무승부 안내 문구
- 이긴 줄 강조, 마지막에 둔 돌 표시
- 무르기(한 수씩 되돌리기, 승부가 난 뒤에도 가능), 새 게임
- 키보드: 칸은 버튼이라 Tab으로 이동, 방향키로 판 위 이동, Enter/Space로 착수
- 화면 읽기 프로그램용 칸 이름(예: "3행 5열, 흑")

## 구조

- `<script id="omok-core">`: 화면과 무관한 게임 로직(`createGame`, `play`, `undo`, `findWinLine`).
- `<script id="omok-ui">`: 판 그리기와 입력 처리.
- `tests/omok.test.mjs`: `omok-core`만 꺼내 Node `vm`에서 시험. `npm test`로 실행.

## 작업 순서(작업마다 커밋)

1. 계획서
2. 게임 로직과 시험
3. 화면
